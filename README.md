# U know enough?

What I want to resolve is that, learning and reviewing general knowledge can sometimes become repetitive when information is only studied by reading or memorizing it. Interactive games can make this process more entertaining by allowing users to test what they know while receiving immediate feedback about their answers.
For this reason, my project will create a quiz game in which the player can answer questions, earn points, advance through different difficulty levels, and see their final results.
My project is going to be an interactive game of general knowledge questions, called U know enough?. The game will have three levels: easy, medium and hard, each one containing five multiple choice questions, and every question will have 4 possible answers. The questions in each level will be randomized, to pass a level the player must get 3/5 correct.
I think this will be an interesting game because it challenges the player to learn and show their knowledge.

1.Start the program.
2.Display the title "U know enough?"
3.Display the instructions of the game
4. Load the questions for the current level.
5.Randomly select 5 questions from the available questions for that level.
6.For each question:
  >Display the question.
  >Display four possible answers: A, B, C, and D.
  >Ask the player to enter an answer.
  >Check that the answer is valid.
  >Compare the player's answer with the correct answer.
7.If the answer is correct:
  >Display "Correct!"
8.If the answer is incorrect:
  >Display "Incorrect."
9.Continue until the player has answered all 5 questions in the level.
10.Count how many questions were answered correctly during that level.
11. If the player answered at least 3 out of 5 questions correctly:
  >Show: You can move on!!
12.If the player answered fewer than 3 questions correctly:
  >Show: Go back!!!!!!
13.Repeat the process for the Easy, Medium, and Hard levels.
14.After completing all three levels, display the final results:
  >Total correct answers
  >Total incorrect answers
  >Final score
